# Architecture

The Vue SPA talks to same-origin `/api/v1` through Nginx. FastAPI validates mutations, authenticates sessions and writes PostgreSQL transactions. It never starts scanner processes. A run snapshots the validated effective configuration and records its initiating user. Definitions may contain only URLs; at launch their resolved, deduplicated IPs become the bounded snapshot target list, while the editable definition retains an empty explicit target list. Later connections must still match that frozen scope. The API has edge-network connectivity for external DNS resolution. Per-URL resolution failures are durably recorded as error endpoint observations, scope events and findings; checkpoints prevent retrying those endpoints during the run. Credentials and screenshots skip error endpoints. If none resolves and no IPs were supplied, the API returns per-URL diagnostics rather than enqueueing an empty run. A partial unique index prevents concurrent active runs of one definition, including paused runs. Related credential references prevent mutation of historical approvals.

The independent scheduler processes the durable `queued` outbox every two seconds and reconciles stale worker heartbeats. Redis publish claims expire after 60 seconds; Redis queue length is capped and deliveries expire. Celery uses late acknowledgements, worker-loss rejection and prefetch one. The worker atomically claims a queued row under a PostgreSQL advisory lock that also enforces the global concurrency limit. Duplicate deliveries are harmless. The database remains authoritative if Redis is lost.

Runs use safe item boundaries. Each RustScan host and Nmap host has an individual checkpoint. Port observations are persisted before service identification, so enumeration failures preserve discovery results. Pause waits for the current process and stops before the next item. Resume requeues the same snapshot and skips completed checkpoints. Stop interrupts the process adapter, terminates its process group, then records a terminal state. A separate process-group guardian detects parent death and kills descendants. A database lease identifies orphaned jobs, which fail closed and retain observations. Scheduler operation does not depend on a free scanner worker slot.

Persistent host identities are normalized IPs; service identities are host/transport/port; endpoint identities are canonical URLs. Run observations reference these stable identities. New, changed and unchanged fingerprints are computed against earlier observations; consolidation records previously observed services missing from the last completed run as `no-longer-observed`. Inventory first/last-seen timestamps are exposed separately from observation creation time. Error events and findings coexist with successful results. Per-target operational failures complete the run with an error count; unrecoverable orchestration failures produce `failed`.

All collections have `page`, `page_size`, `search`, `sort_by`, `sort_order` and applicable status/IP filters. Responses contain items and total/page counts. Database filters, count queries, stable primary-key tie breaks and LIMIT/OFFSET happen before serialization. Nested scan histories and result collections use separate endpoints; the dashboard includes at most one latest-run summary per scan. Table query state is stored in the URL. Status polling is the transport used in this MVP.

UUID values are stored as portable 36-character primary keys. Timestamps are stored as UTC values and serialized with `Z`. Production JSON fields use JSONB; SQLite variants support isolated tests. Alembic contains an explicit initial schema migration, independent of later model edits. The credential key is supplied through a mounted Docker secret. The evidence volume is writable only by workers and mounted read-only by the API; evidence is never publicly mounted by Nginx.

CVE source/publication fields and pending follow-up candidates reserve future integration points. They do not perform enrichment, exploitation or automatic execution. There are no roles or permission tiers.
